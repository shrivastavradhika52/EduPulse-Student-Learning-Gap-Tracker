# 🎓 EduPulse – Student Learning Gap Tracker

**Identify Learning Gaps. Track Growth.**

EduPulse is a web-based student learning gap tracking system designed to help teachers identify students who need academic improvement and monitor their performance over time.

## 📌 Problem Statement

Teachers may find it difficult to identify students' weak subjects or topics and track their academic progress using manual records. EduPulse aims to make this process easier through a simple and user-friendly web interface.

## 💡 Our Solution

EduPulse provides a platform to record student details and academic performance, identify learning gaps, and compare previous and latest marks to monitor improvement.

## ✨ Key Features

- **Student Performance Management:** Add and manage student performance records.
- **Learning Gap Identification:** Identify students who need improvement.
- **Progress Tracking:** Monitor academic performance over time.
- **Performance Comparison:** Compare previous and latest marks.
- **Search Functionality:** Find student records easily.
- **Edit and Delete Records:** Update or remove existing records.
- **PHP Report Generation:** Generate student performance reports through a form.

## 🛠️ Technologies Used

- HTML – Structure of the web pages
- CSS – Styling and layout
- JavaScript – Interactive functionality
- PHP – Report generation
- LocalStorage – Store records in the browser

## ⚙️ How to Run Locally

1. Install and open **XAMPP**.
2. Copy the EduPulse project folder into the `htdocs` directory.
3. Start the Apache server.
4. Open your browser.
5. Visit:

   `http://localhost:8080/EduPulse/`

   *(Use the port configured in your XAMPP setup.)*
